# よみの れんしゅう

漢字の読みを4択で選ぶ、スマホ用の練習アプリ（ホーム画面に追加して使う Web アプリ）。

- 1回30問で必ず終わる。1画面1問、文字入力なし
- 問題や「つぎへ」が出てから0.5秒は、タップを受け付けない（前の画面で押した指が、そのまま次の選択肢に当たるのを防ぐ）。押したボタンの位置（上から1〜4）と、受け付けなかったタップの数を「結果」に記録する
- 集計：Apps Script が、ゲームが終わるたびに（または20分ごとに）「集計_日」「集計_語」タブを作りなおす。習熟の段階はアプリと同じ間隔反復で数える。手で作りなおすときは Apps Script で `updateSummary` を実行する
- 間違えた語は 1日後 → 3日後 → 7日後 → 14日後 → 30日後 に出し直す
- 初めて正解した語は 14日後に1回だけ確認する
- 30問の配分：期限が来た復習 最大15、前に正解した語 5、残りを新しい語（逆向きの問題があるときは、その分だけ読みの問題をへらす）。新しい語が足りないときは、前に正解した語 → 復習 の順で埋める（苦手な語の復習は、やりなおしもふくめて15問まで。正解済みの語がないときだけ、それより多くなる）
- きろくの画面（ホームの「きみの きろく」）：ふえていくものだけを見せる。読めた語の数（1秒以上かけて正解したことがある語。「集計_日」の「読めた語」と同じ数え方）、やった日ごとの棒グラフ（その日までの合計なので下がらない。新しい日から7日）、前にまちがえて今は読める語を3つ（2回以上まちがえた語を先に）、続けた日数。正答率・まちがいの数・答える速さは出さない。早押しの回は数えない。棒がのびる動きは「うごき」がオフのときと、動きを減らす設定の端末では出さない
- 例文は1語につき最大6つ（「例文」「別の例文1〜5」）。初めて出るときは「例文」、2回目からは6つの中からランダム。どれを出したかを「結果」に記録する
- 早押しの回：1問の時間の真ん中（0.1秒単位にまるめる）が1秒未満の回は、記録（「結果」タブ）には残すが、覚えた度合い（間隔反復・やりなおし・逆向きにできる語）には数えない。画面には何も出さない。連続日数と1日の回数には入る。集計タブでも数えず、「集計_日」の「早押しの回」に回数だけ出す
- 演出「静か」：問題タブの「演出」が「静か」の語（物語の悲しい場面など）は、正解してもはじける演出やかけ声を出さず、「○ せいかい」としずかな音だけにする。1回に5問まで（逆向きもふくめる）。こえた分は次の回にまわす
- テスト文：学校のテストに近い文（2年生までの字は漢字、3年生以上はひらがな、区切りのスペースなし、人の名前なし）。読みの問題の復習・2週間後の確認・正解済みでは、テスト文があればそれを出す（新しい語・やりなおし・逆向きでは使わない）。教科書の物語からとった語は、例文とテスト文を物語の文にする（物語の文はスプレッドシートにだけ置き、このリポジトリには入れない）。出した例文は「テスト文」と記録する
- 逆向きの問題：「よみ」を見て、正しい漢字を4択で選ぶ。1回30問のうち最大5問。読みの問題で正解したことがある語（1秒以上かけて正解）で、「逆の誤答1〜3」がそろっている語だけ。読みとは別に間隔反復を数える。同じ回に、同じ語の読みの問題は出さない
- 1日15回まで。毎日の目標は1回（連続日数は1回で数える）、2〜15回目はおまけ。2回目からは、その日に間違えてまだ正解しなおしていない語を「やりなおし」として先に出す（間隔反復の段階は進めない）。どれも30問
- オフラインでも遊べる。記録は通信できたときに送る
- 効果音：正解は明るい2音、間違いはやわらかい1音、30問おわりは短いファンファーレ。3問つづけて正解するとビートがのる。ホーム画面でオン・オフできる
- 読み上げ：間違えたとき、正しい読みを端末の日本語の声で読む（「もういちど きく」でゆっくりもう一度）。「おと」がオフのときと、端末に日本語の声がないときは読まない。「おうちのひと」画面で声の有無を見て、ためせる
- 演出（ダンス）：正解すると粒がはじけて英語のかけ声（NICE! など）。3・5・10問つづけて正解すると強くなる。0.85秒で消える。間違えたときは出さない。ホーム画面の「うごき」でオン・オフ。動きを減らす設定の端末では出さない
- おわりの画面：30問やりきったお祝い（ステージ、FINISH!、正答率）は毎回。前回より正答率が上がった日は LEVEL UP!、全問正解の日は PERFECT! をたす。前回より下がった日は、前回の数字を出さない
- おためしモード：答えても記録しない。親の端末は「おためし専用」にできる（setup.html のチェック、または「おうちのひと」画面）。子どもの端末では「おうちのひと」画面から1回だけ試せる。出題はその日の本番と同じ決め方

## ファイル

| ファイル | 中身 |
| --- | --- |
| `index.html` `style.css` `app.js` | 画面 |
| `logic.js` | 出題・間隔反復・日数の計算 |
| `sound.js` | 効果音（音声ファイルは使わず、その場で作る） |
| `fx.js` | 演出（正解したとき、おわりの画面） |
| `speech.js` | 読み上げ（端末の読み上げ機能を使う） |
| `sw.js` `manifest.webmanifest` `icons/` | オフライン対応とホーム画面用 |
| `setup.html` | 子どもの端末に接続先を入れるための QR コードを作るページ |
| `gas/Code.gs` | スプレッドシートに紐づける Apps Script（API） |
| `vendor/qrcode.js` | QR コード生成（qrcode-generator, MIT） |

## データについて

このリポジトリは公開されています。問題・記録・名前などのデータはここに置かず、すべて Google スプレッドシートに入れます。
接続先の URL とアクセスキーもコードには書かず、端末ごとに保存します（`#u=…&k=…` のリンクで渡す。`#` 以降はサーバーに送られません）。

## 更新するとき

アプリのファイルを変えたら、`sw.js` の `VERSION` を上げる（端末に置いてある古いファイルを入れかえるため）。
